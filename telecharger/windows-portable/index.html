Ensuite : lancer

  1. Placez Alixo-Portable.exe où vous voulez (Bureau, clé USB…) et double-cliquez : rien n'est installé.
  2. Si Windows SmartScreen affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis sur Exécuter quand même.

La version portable ne se met pas à jour toute seule : quand Alixo signale une nouvelle version, revenez sur cette page pour récupérer le nouveau fichier. Pour des mises à jour automatiques, préférez l'installateur.
